# Development Documentation

The development set is intentionally limited to three durable documents:

- [design.md](design.md): architecture, IR boundaries, execution model, and
  long-lived design decisions
- [progress.md](progress.md): current capability, priorities, deferrals, and
  latest verification baseline
- [standards.md](standards.md): implementation workflow, ownership, acceptance,
  testing, release, and documentation rules

Read them in that order when starting repository work. Package-specific usage
belongs in package `README`s, runnable guidance belongs in `examples/`, and
release history belongs in `CHANGELOG.md`.
